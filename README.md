# Wildfire-Fuel-Mapping
L2HFuelNet: end-to-end DL for 10 m wildfire fuel maps from multi-source RS (S1/S2/DEM) and 30 m labels. Dual-encoder U-Net (SwinT+ASPP), composite L2H-FL loss, uncertainty mapping, and benchmarks vs UNet/DeepLab/ViT.
